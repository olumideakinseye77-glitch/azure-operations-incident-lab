# AI-Assisted Azure Operations & Incident Lab

## Purpose

I am building this project to challenge myself with Azure troubleshooting,
Linux administration and Python automation.

My goal is to investigate faults, collect evidence, restore service and
explain what happened. AI will help suggest possible causes and recovery
steps, which I will review against the evidence before taking action.

## Status

Planning and repository setup. No Azure resources deployed.

## Planned exercises

- Diagnose and recover a stopped Linux service.
- Investigate an incorrect application configuration.
- Safely simulate and investigate disk pressure.
- Collect diagnostic evidence using Python and Bash.
- Query operational logs using KQL.
- Document each incident, recovery and lessons learned.

## Tools

Azure, Linux, Python, Bash, Terraform, GitHub and Azure Monitor.

## Cost control

Deploy resources only for practice sessions.
Capture useful evidence and remove billable lab resources afterwards.
Check for remaining resources after cleanup.

## Evidence handling

Do not commit credentials, Terraform state or raw diagnostic logs.
Review and sanitise evidence before publishing it or sharing it with AI.
